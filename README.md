# Paper Plate for Android

Download: [Paper-Plate.apk](https://github.com/joshuagrigson/red_night/raw/paper-plate-app/Paper-Plate.apk)

Open the link on the phone and allow the install when Android asks. Paper Plate turns what's in your
kitchen into a recipe: snap the fridge, type or say what you have. Installing over an older copy keeps
your recipes.
