# Grigson TV for Android

Download: [TV-Remote.apk](https://github.com/joshuagrigson/red_night/raw/tv-remote-app/TV-Remote.apk)

Open the link on the phone, allow the install when Android asks, then open the app on the same Wi-Fi as
your TV. It finds LG, Vizio and Roku TVs and walks you through pairing. Installing over an older copy keeps
your settings.
